## 🔄 DATA FLOW

```
User Action
    ↓
Component State Update
    ↓
API Call (services/api.js)
    ↓
Backend Response
    ↓
Update Component State
    ↓
Re-render UI
    ↓
User Sees Result
```

### Example: Login Flow
```
User enters email/password
    ↓
Clicks "Sign In"
    ↓
handleSubmit() called
    ↓
loginUser() API call
    ↓
Backend validates credentials
    ↓
Returns access token
    ↓
login() saves to localStorage
    ↓
useAuth() updates context
    ↓
PrivateRoute allows access
    ↓
Navigate to /chat
```

### Example: Chat Message Flow
```
User types message
    ↓
Clicks Send or presses Enter
    ↓
handleSend() called
    ↓
Add user message to state
    ↓
Set loading = true
    ↓
sendMessage() API call
    ↓
Backend AI processes
    ↓
Returns AI response
    ↓
Add AI message to state
    ↓
Set loading = false
    ↓
Auto-scroll to bottom
```

```

    ↓

    ↓

    ↓

    ↓

    ↓
PrivateRoute allows access
    ↓

    ↓
Click "Logout"
    ↓

    ↓

    ↓

```

## 🔗 API ENDPOINTS USED

```
Backend Base URL: http://localhost:8000

POST /auth/register
├── Body: { email, password }
├── Response: { access_token }
└── Used in: Register.jsx

POST /auth/login
├── Body: { email, password }
├── Response: { access_token }
└── Used in: Login.jsx

POST /chat/
├── Body: { message, conversation_id }
├── Response: { conversation_id, reply }
├── Auth: Bearer token required
└── Used in: ChatDashboard.jsx
```
